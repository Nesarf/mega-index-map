# Mim: the mascot, and what art the project keeps

Mim is this project's mascot. The character was generated by the repository author and belongs to them; it is
not part of the MIT grant that covers the code.

## What lives in the repository

| File | Size | Use |
|---|---|---|
| `docs/mim-chibi.webp` | 320 px, 25 KB | the Q-version, used at the top of both READMEs: outward-facing material leads with it |
| `docs/mim.webp` | 900 px, 162 KB | the full-body art |
| `docs/mim-icon.webp` | 256 px, 19 KB | square icon crop |

Two standing rules decided by the author (2026-10-15):

1. **Everything that enters this repository is WebP.** It is small, GitHub renders it, and it avoids the
   name-versus-content mismatch of shipping, say, WebP bytes under a `.png` name.
2. **Outward-facing material leads with the Q-version.** Announcements, social posts and README headers use
   the chibi; the full-body art is for places that can afford the height.

The originals (uncompressed masters and the expression sheet) are kept outside the repository, in the
author's own art folder, and are not modified by anything here. Working copies of the derived images live in
the author's scratch area, not in the repository: only the three files above are shipped.

## Art the project would still like

Ordered by usefulness. Nothing here is promised; it is a list for whoever generates art next.

**Expressions (four, most useful first)**
1. Apologising, embarrassed - this project says "I got that wrong" often enough to deserve a face for it
2. Hesitating, unsure
3. Staring at an error, thinking
4. Being praised, flustered

**Costume and scene (one each is enough)**
1. Working: goggles pulled down, apron, sleeves rolled
2. Winter: heavy coat and scarf
3. Hot spring: yukata and a small wooden basin
4. Working from home: pyjamas, sitting on the crate with the instrument case

**Props that say what the plugin does**
1. Holding a key - manual decryption of a sensitive record
2. A notebook full of operation names - the tool list
3. A cart of record cards - writing and registering
4. A hand-lettered sign with whatever number is being argued about

## Specs for new art

- Single image: PNG or WebP, transparent background, subject between 1000 and 1500 px tall, sRGB
- Expression sheets: one image, 3x4 or 4x4, square cells, at least 2000x2000 total
- **The format must match the extension.** A file once arrived here claiming to be one thing and holding
  another; the check that caught it was a two-line header read, and it is worth running every time.
- No uncompressed bitmaps. A 72 MB BMP of the sheet compressed to 2.35 MB as WebP, about one thirty-first.
- Transparent backgrounds should not carry white fringes.

## Naming

- Full body: `Mim_full_<variant>_<height>px.png`
- Expression: `Mim_expr_<expression>_<height>px.png`
- Chibi panels cut from the sheet: `mim-Q-p<panel>-<name>.png`
- Shipped sizes: `docs/mim.webp`, `docs/mim-chibi.webp`, `docs/mim-icon.webp`
